# Handoff Protocol

Use when switching AI windows/tools.

## Minimal handoff bundle

Always provide:
- `00-CHARTER.md`
- `02-CURRENT-STATE.md`
- `03-DECISIONS.md`
- `04-INTERFACES.md`
- current task file

## New agent instruction

Use:

"Read the provided project-control files first. Do not redesign frozen decisions. Execute only the current task. Non-blocking findings go to backlog. Return evidence against the predefined acceptance criteria."

## Required handoff output

- Current task
- Current status
- Files changed
- Tests/evidence
- Blockers
- Deferred findings
- Next task
